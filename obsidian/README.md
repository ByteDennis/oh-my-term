# obsidian

Vault scaffolding: folder skeleton, note templates, Obsidian settings, and the
scripts that keep settings in this repo while content stays off it.

The vault itself holds work content and is never committed here.

```
templates/      note templates
dot-obsidian/   Obsidian settings, mirrored out of the real vault
scripts/        set up a vault, sync settings back, check for leaks
docs/           how to run it, and what to take from the reference vaults
```

Start with `docs/first-week.md`. The plan behind it is in
[`plans/obsidian-vault.md`](../plans/obsidian-vault.md) on `main`.
